The single sentence a house cat would say in the five seconds after sweeping a glass off the table. No apology, no confession — just the most convincing case the cat can make for itself: the glass was empty, the table was dusty, gravity had already filed its request, and the rug needed watering anyway.

## Run it

```sh
node main.ts
```

Prints the sentence to stdout and writes the exact same sentence to `/output/entry.txt` (156 characters, UTF-8, no trailing newline). The program refuses to write a line outside the 1–200 character gate.
